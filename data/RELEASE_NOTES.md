# Verified public market data snapshot

This release contains seven tar files holding 1,953 selected public Binance ZIP archives (8,030,500,775 bytes of source data). Each ZIP has been checked against its previously recorded size and SHA-256 digest before packaging.

The collection covers USD-M futures trades, aggregate trades, klines, mark-price klines, funding rates, and selected spot klines used by the project. It is not a complete history for all symbols or every experiment. See the repository's [data guide](https://github.com/ljyzjy/crypto-breakout-research/tree/main/data) and [source manifest](https://github.com/ljyzjy/crypto-breakout-research/blob/main/data/source-manifest.json) for file-level coverage, upstream URLs, hashes, and extraction instructions.

Upstream source: https://data.binance.vision/
