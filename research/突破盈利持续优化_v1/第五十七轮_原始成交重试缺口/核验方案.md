# 原始成交差异的两例重试核验

已有异常清单中，2024 年一次重试方案原本未知的候选里，两个 ETHUSDT 个案具有相同特点：此前原始成交与一分钟柱 OHLC 一致，聚合成交只有开盘价不同；首次越界和五秒主动成交额在两种口径一致，首次入场未发生，但五秒参考价回到边界内，因此仍可能发生一次重试。该集合基于先前数据质量复核记录选取；在写本方案时没有读取这两例后续重试的结果。另一个五秒参考价在边界外的 XRPUSDT 已在第 54 轮单独复核，不列入本轮。

在不更改冻结回测的前提下，仅按以下规则独立重读和核验这两个事件：

1. 重新获取该日官方一分钟、聚合成交、原始成交档案，核对官网完整 ZIP SHA、字节数和此前记录；对触价分钟核对原始成交的 OHLC、数量及成交量，并核对首次突破方向、时间和价格、首次五秒参考和严格窗口内主动买卖额。对触价发生前的同一十五分钟柱内完整分钟，核对原始候选的“此前尚未越界”条件；核对固定 11 币候选的可交易方向、边界、止损和双币资格。
2. 用既定第 47 轮规则，从五秒参考之后寻找该方向首次再次越界，比较原始和聚合成交给出的重试时间、价格、重试五秒参考及主动成交量。原始成交与聚合成交条数因聚合方式不同可以不同，但各自须满足最少三笔条件，且主动买卖额、方向状态必须一致。
3. 如没有重试、重试过滤或风险预检拒绝，只有相关时序和判断全部一致时才在单独敏感性分析中记为已知不下单；若合资格入场，须进一步核对两种逐笔数据的两个杠杆下入退场时点及价格、止损止盈原因，重算手续费、滑点、资金费和分钟标记价风险，并通过独立路径核验后才能列为已知机会。任一缺口或冲突保留未知。
4. 同时报告原冻结结果、变化后的已知和未知数量、盈亏与胜率上界。原有结果不得重写；同一交易所的多份数据不是跨交易所验证，事后排查也不是独立样本。不得将数据修复结果解释为新策略盈利。

两例观察 ID 固定为 `touch|ETHUSDT|1719247620000` 和 `touch|ETHUSDT|1707902880000`。读取顺序只按档案字节大小安排，不按结果筛选。
