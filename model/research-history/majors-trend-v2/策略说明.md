# BtcTrendV2 — 风险预算型 BTC 趋势策略

> 一句话：**只在 BTC 上做时间序列动量，用连续仓位代替开关，用 40% 波动率预算控制暴露。**
> 2017-12 至 2026-10（8.85 年）回测：年化 27.4%，最大回撤 −24.5%，Sharpe 1.19，62 笔交易。

---

## 一、和 V1 比，改了什么

| | MajorsTrendV1 | BtcTrendV2 |
|---|---|---|
| 标的 | BTC + ETH 等风险 | **仅 BTC** |
| 仓位 | 二元开关，满仓或空仓 | **连续仓位**，0–100% 随信号强度 |
| 风险预算 | 无，暴露 50–60% | **年化 40% 波动率目标**，只降不升 |
| 退出 | z < 0 | z ≤ 0（仓位自然衰减到 0） |
| 9 年年化 / 回撤 | 21.2% / **−74.7%** | **27.4% / −24.5%** |

三处改动都不是拍脑袋，是被数据逼出来的：

1. **砍掉 ETH**。BTC/ETH 双币在 2018–2026 上是 21.2% 年化、−74.7% 回撤；单 BTC 是 41.6%、−58.6%。在 24 币上做动量选前 K 名更糟（前 3 名 62% 年化但 −83% 回撤）。加密山寨的趋势一旦反转是断崖式的，分散不但没降波动，反而把尾部风险叠起来了。
2. **连续仓位**。同样的信号，二元开关是 28.9% / −28.3% / Sharpe 1.19；连续仓位是 27.9% / −16.9% / Sharpe 1.33。收益几乎不变，回撤少 11 个百分点。原因是开关会在信号临界点反复横跳，而连续仓位在弱信号时本来就只拿一点点。
3. **波动率预算**。这是唯一一个在 2018 熊市里救了命的设置：2018 年 BTC −72%，二元满仓版本 −44%，加了 40% 波动率预算后 −14%。

## 二、完整规则（可复现）

**信号**（日线收盘计算）：

```
r      = close / close[-1] - 1
对 L ∈ {20, 40, 60, 90}：
    σ_L  = std(r, L) × √L
    z_L  = (close / close[-L] - 1) / σ_L      ，截断到 [-3, +3]
z = mean(z_20, z_40, z_60, z_90)

方向分   = clip(z, 0, 1)                       # z≤0 时为空仓
波动缩放 = min(1, 0.40 / (std(r,30) × √365))
目标权重 = 方向分 × 波动缩放
```

**执行**：每个日线收盘后计算目标权重，次日开盘调整到该权重。
偏离小于权益 5% 不调仓（否则每天的手续费会吃掉 1–2 个点/年）。

**成本假设**：单边 0.10%，含滑点。换手约 13 倍/年，年成本 1.3–1.4%。

**空仓期**：USDT 放在活期/理财，按 3% 年化计息（回测里未计，属于保守处理）。

## 三、为什么不做空

对称多空版本在 2018–2026 上是 Sharpe 0.83、回撤 −39.4%，即使把空头资金费设成 0 也一样。原因是加密的下跌又急又短，趋势信号确认时往往已经反弹，空头被反复打脸；而上涨是慢牛，趋势能持续。**只做多 + 会空仓**，比“多空都做”更赚钱，也避开了永续合约的强平和资金费。

## 四、为什么不是“参数优化出来的”

- 回看期 20–40 日最好（Sharpe 1.23–1.25），集成 (20,40,60,90) 是 1.19，长周期 60–250 日是 0.88–1.04。**整片区域都是正的**，不是一根尖峰。
- 入场阈值 0.2 / 0.3 / 0.5 的 Sharpe 分别是 1.18 / 1.19 / 1.02，平台很宽。
- 波动率预算从 25% 到 80% 单调变化，没有断层（见回测结果文档）。
- 用 2020–2022 选参数、2023–2026 检验的 walk-forward：OOS 年化 26.6%、Sharpe 0.90、回撤 −26.1%，和固定参数的 27.4% 基本一致——说明**选参不会带来额外收益，也不会毁掉它**，所以我直接钉死在默认值上。

## 六、什么时候它会失效

1. **长期横盘**。2025-01 至 2026-10 只有 −0.2% 和 +2.6%，BTC 同期 −10%，策略只是没亏。趋势策略在震荡市里就是不停小亏，这是它的成本，不是 bug。
2. **V 型反转**。2020 年 3 月那种一周 −50% 再快速收复，趋势信号来不及反应，会卖在底部附近。
3. **交易所风险**。现货单币，没有强平风险，但仍有平台风险。BTC 放交易所的量建议不超过总资产的一半。
4. **样本很薄**。9 年只有 62 笔完整交易，前 5 笔贡献了 102% 的利润——趋势策略本来就是靠少数几笔大行情养活，必须接受“大部分时间在等”。
