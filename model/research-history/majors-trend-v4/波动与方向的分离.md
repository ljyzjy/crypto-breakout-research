# 为什么「识别得准」和「赚得到钱」是两件事

对 `c-users-win11-documents-codex-2026-2`（15 分钟大突破前瞻识别器）的复盘，以及它对本项目「信心加杠杆」问题的回答。

---

## 一、它自己的数据已经说了答案

固定 18 币，2026-04-27 至 2026-10-31，逐月重训：

| 模型 | 精确率 | 前向 15 分钟收益均值 | 胜率 |
|---|---|---|---|
| 较早首次越界 | 4.20% | −0.0038% | 44.9% |
| 既有严格条件 | 8.37% | **+0.0165%** | 45.2% |
| 滚动树模型 | 12.87% | −0.0102% | 45.0% |
| 树模型 + 主动成交额 | 13.05% | −0.0067% | 45.0% |

**精确率提升 3.1 倍，前向收益没有任何改善，胜率被钉死在 45%。**

再看「柱前观察 + 柱内确认」这一档：命中率 24.60%（相对随机 1.30% 是 19 倍），但 2126 次警报的 15 分钟同向价格变化是 **−0.0455%**，中位数 −0.1042%。

**命中率从 11% 提到 24.6%，收益从 −0.0226% 掉到 −0.0455%。**

这个模式在三个时期、九种模型里重复出现。它不像是实现 bug，像是结构性的。

## 二、根因：模型学的是波动，不是方向

用这个项目自己的 917,855 根 15 分钟柱，同一批特征（`ret1`/`ret4`/`position`/`volratio`/`activity`），两个标签：

- 标签 A（波动）：**下一根柱 `|实体| ≥ 1%`**
- 标签 B（方向）：**下一根柱是阳线**

时序切一半训练一半检验，算单变量 AUC：

| 特征 | 波动 AUC（前 / 后） | 方向 AUC（前 / 后） |
|---|---|---|
| ret1 | 0.493 / 0.526 | 0.487 / 0.484 |
| ret4 | 0.490 / 0.544 | 0.492 / 0.488 |
| position | 0.488 / 0.531 | 0.486 / 0.483 |
| **volratio** | **0.603 / 0.609** | **0.501 / 0.501** |
| **activity** | **0.608 / 0.612** | **0.500 / 0.502** |

**成交活跃度预测「会不会大动」的 AUC 是 0.61，预测「往哪动」的 AUC 是 0.5005。**

把全部特征等权排名求和：波动 AUC 0.542/0.578，方向 AUC 0.490/0.486。

按时间分十段独立检验：

| | 波动 AUC | 方向 AUC |
|---|---|---|
| 10 段范围 | 0.582 – 0.630 | **0.476 – 0.494** |
| 均值 | 0.607 | 0.486 |

**方向 AUC 在十个独立时间段里全部低于 0.5。** 这不是噪声，这是稳定的轻微反转。

## 三、所以「精确率」这个词本身有陷阱

「大突破」的定义是「同向实体 ≥ 1% **且** 收盘越过此前 16 柱同向边界」——它是「波动」和「方向」的合取。

模型能预测前半段（会波动），不能预测后半段（往哪边）。所以：

- 提高精确率 = 更准地识别「会动的时刻」
- 提高收益 = 需要「往哪动」
- **两者不是同一件事，而且后者不可得**

这解释了为什么 229/2126 次警报发出时柱子已经走了 1%——模型在波动已经发生后确认它，然后在方向未知的情况下追进去。

## 四、这同时回答了「能不能在把握大的地方加杠杆」

上一轮在日线数据（2020-2026，2496 天）上的结论是：倾斜杠杆全败，Sharpe 恒定 1.24-1.25。

现在有了机制层面的解释：

**策略里唯一可预测的维度是波动率，而它已经被用掉了**——仓位公式 `w = clip(z,0,1) × min(1, 0.4/vol)` 里的 `0.4/vol` 就是波动率目标。

剩下的维度（信号强度、多周期一致度、趋势质量、回撤深度……）在方向上是零信息的（日线：胜率恒定 51-53%；15 分钟：方向 AUC 0.486）。

**在一个零信息的维度上加杠杆，等于纯加风险。** 这不是运气不好，是数学。

## 五、顺手关掉的两条路

### 5.1 短周期反转（真实，但吃不到）

方向 AUC 0.486 说明 15 分钟级别有稳定反转。按 `|ret1|` 分位做反向：

| 门槛 | 样本 | 毛收益 | 扣 8bp 往返 | 胜率 | t |
|---|---|---|---|---|---|
| \|ret1\|>p90 | 91,813 | +0.96bp | −7.04bp | 51.7% | 3.42 |
| \|ret1\|>p95 | 45,912 | +1.46bp | −6.54bp | 51.7% | 2.99 |
| \|ret1\|>p98 | 18,381 | +2.35bp | −5.65bp | 51.3% | 2.22 |
| \|ret1\|>p99 | 9,200 | +3.51bp | −4.49bp | 51.2% | 1.80 |
| \|ret1\|>p99.5 | 4,607 | +4.22bp | −3.78bp | 52.2% | 1.15 |

反转是统计显著的（t=3.42），毛收益随门槛单调上升，但**最好的一档也只有 4.22bp，是 8bp 成本的一半**。而且门槛越极端，t 值越低。

这是有效市场的典型形态：套利空间被磨到成本线以下。**短周期方向交易不可做。**

### 5.2 执行时点优化（日线层面没有空间）

用 15 分钟数据测「开盘后到各时点」的逆向幅度，只有 127 个有仓日，所有时点的 t 值都 < 1.2，纯噪声。

换日线全样本（2500 天）测同向跳空：

- 均值 **−0.01bp**，中位 0.00bp，**t = −0.65**，n = 1490
- 前半 −0.01bp，后半 +0.00bp
- 逐年 2020-2026 全部在 ±0.04bp 以内

**趋势日的开盘跳空是零均值的。开盘既不是追高也不是折扣。** 所以「等回调再进」没有系统性的便宜可占。

## 六、下一步的筛选标准（这是本轮最有用的产出）

以后任何新特征、新数据、新模型，**先过这一关再谈回测**：

```
用该特征预测「下一根 K 线涨还是跌」
AUC 如果仍在 0.49–0.51 之间 → 直接放弃，不要写策略
只有方向 AUC 显著 > 0.52 且分半样本都成立 → 才值得进入回测
```

这个筛子很便宜（几行代码），能省掉 90% 的无效工作。上一轮十个信心维度、这一轮九个突破模型，如果一开始就用这个筛子，会省很多时间。

**能通过这一关的信息，不可能来自 OHLCV 的任何变换。** 因为 OHLCV 已经被现有策略榨干了（波动进了仓位，方向为零）。候选必须换数据类型：

| 数据 | 为什么可能领先方向 |
|---|---|
| 订单簿失衡（挂撤单） | 挂单是未成交的意图，先于成交 |
| 主动买卖量（taker buy/sell） | 区分谁在吃单 |
| 持仓量 OI 变化 | 价格与 OI 背离 = 增量资金还是平仓 |
| 大户/多空账户比 | 仓位分布，拥挤度 |
| 清算数据 | 强制平仓造成非自愿成交 |
| 资金费率**变化率** | 现有策略只用水平分位，变化率未用 |
| 稳定币流入 | 场外资金，领先于买盘 |

其中 2-6 币安公开 API 可取，不需要额外付费数据源。
