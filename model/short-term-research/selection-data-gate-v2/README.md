# 小时选币研究：数据隔离与官方手续费修订

网页：http://127.0.0.1:8765/selection-research

本目录只用于回测研究。当前 DailyMomentum 模拟引擎、账户、配置和策略文件不由本研究修改。

当前基准成本为币安官方普通用户 USDT 永续 Taker 单边 0.05%，核验日期 2026-11-13。成交按立即成交建模，因此不采用 Maker 费率。单边滑点 0.05% 是估计值；历史资金费逐笔结算。没有读取账户 VIP、BNB 折扣或优惠，也没有重建每个历史日期的手续费档位。费用按成交名义金额计，不按保证金计。

保留三层证据，避免覆盖失败结果：

1. `../selection-research-v1`：最初固定的 84 场景。小时版部分路径因标记价格缺失无效。
2. 本目录 `protocol.json`、`metrics.json`、`assessment.json`：用户授权数据可用性隔离后的旧成本 84 场景。单边手续费仍为 0.10%。
3. 本目录 `official-protocol.json`、`official-metrics.json`、`official-assessment.json`：用户要求采用官方标准手续费后的当前 84 场景。基础手续费 0.05%，双倍 0.10%，三倍 0.15%，另外测试 5 分钟延迟与两个历年子区间。

`frozen.json`、`official-frozen.json` 保存规则和数据哈希。费率调整依据用户请求及外部官方收费表，不根据哪个手续费能使策略盈利而选择。

数据隔离统一适用于所有币：一根已结束且有交易的永续成交柱没有对应标记收盘价，则从该柱结束后隔离该币，本轮不自动恢复；按原评分递补。缺失前的历史记录保留。若缺失时已有持仓、或当前成交价格不可用，仍中止该路径，不虚构平仓。历史归档缺失不证明当时线上系统同样缺失。

每小时重排只改变评分更新时间，30/60 日动量跨度及跳过最近 7 日等参数保持固定。资格池来自前一完整日，额外杠杆仍每日评估，上限 5 份底仓数量。每种评分均有 1× 和动态上限 5× 两条独立账本，周度对照保留。

复核顺序：

```text
preflight_revision.py  # 原实验复现、缺失隔离的因果时点与冻结
run_selection.py      # 旧成本84场景
run_official.py       # 当前官方标准成本84场景
assess_official.py    # 完整结果与既定筛选标准
validate_results.py   # 账本、资金费、订单前缀、杠杆约束、重采样、模拟隔离
write_interpretation.py
```

已生成的结果通过缓存读取；复现时不得改变冻结规则或数据。`fee-protocol.json` 与 `run_fee_reference.py` 是用户进一步要求将官方费率设为默认之前准备的补充方案，未执行，已由 `official-protocol.json` 和 `run_official.py` 取代。

来源及具体改写见 `sources.json`。这些是可检验的公开思想改写，不是论文模型或基金内部策略的完整复制。过去历史已经反复研究，不具备独立样本外的含义。未按照回测结果继续搜索窗口、权重或阈值。
