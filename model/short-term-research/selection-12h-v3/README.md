# 用户指定的12小时换币对照

本轮在原有学术因子与公开方法研究上，仅把选币、入场与动量退出的决策时钟改为 UTC00:00/12:00（北京时间08:00/20:00）。止损与抵押品检查仍为5分钟，杠杆仍每日评估，数量上限5份底仓。相同币种仍入选时不强制交易。

官方普通用户USDT永续Taker手续费为单边0.05%；滑点单边0.05%是估计值，历史资金费另计。压力手续费0.10%/0.15%，还有额外延迟5分钟、2025年、2026年子区间。账户VIP和BNB折扣未读取；这不等于逐期复原账户实收费用。

5种评分×1×/动态5××6场景=60条新增记录。与上轮14版本×6场景共84条记录合并展示为24版本、144条记录。`metrics.json`仅含本轮，`all-metrics.json`及`metrics.csv`含完整对照。各版本都是独立研究账本，未替换DailyMomentum模拟。

按顺序运行 `preflight.py`、`run_study.py`、`assess.py`、`validate.py`。使用项目现有Python环境和冻结数据。`cadence_engine.py`复用上一轮执行代码及因子，未改动父版本文件。`frozen.json`包含父版本及本轮规则哈希。

`protocol.json`在任何12小时结果产生前保存。频率由用户指定，未搜索其他频率；比较结果即使不盈利也保留，不据此再调整权重、窗口或阈值。数据缺失隔离与来源说明见 `../selection-data-gate-v2`，原缺失前的失败路径保留在 `../selection-research-v1`。
