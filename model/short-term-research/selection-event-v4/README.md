# 卖出后按排行榜补位

本轮由用户明确提出：换币在仓位卖出后进行。原12小时、每小时与周度研究保留，当前DailyMomentum模拟不变。

规则：

1. 初始两个空位按最新已知排行榜，从最高合格名次开始建仓。
2. 已有持仓不因排名下降、离开资格池、或到了固定换币时间而卖出。其30日动量由自身连续已结束小时价格计算，不因掉出选币池变成零信号。
3. 基础仓仍按原4%价格止损退出；方向退出仍在UTC00/12点检查。风险检查为5分钟，杠杆每天检查，上限5份底仓。
4. 某基础仓卖出后，对应空位最早在下一个可执行5分钟柱补位。柱内止损只在柱结束后已知，不能用同一柱的后续信息提前买入。
5. 根据该时点已结束小时排行榜，跳过已持有、数据无效、冷却/入场条件不通过的币，选择最高合格名次。另一持仓独立保留；没有合格币则保留现金并继续检查空位。

本轮只给原动量与四因子方案增加事件补位版，分别测试1×与动态上限5×，共4版本×6场景=24条。完整网页合并此前24版本144条记录，共28版本168条记录。

费用继续为币安官方普通用户USDT永续Taker单边0.05%；滑点单边0.05%为估计值，历史资金费单列。压力手续费0.10%/0.15%，另测延迟5分钟与两个历年子区间。账户VIP/BNB优惠未读取，历史费用档位未逐期还原。

数据使用同一2025-01-01至2026-04-26区间和原信号快照。补齐52个潜在补位候选在首次可能买入至区间结束的执行数据，避免把缺少旧实验数据的币误当不可交易。此归档联合清单只用于数据加载，不表示在回测起点提前知道未来入选名单。实际决策只读取当时资格与排名。新旧数据重叠校验，并复现原12小时对照。

按 `prepare_history.py` → `preflight.py` → `run_study.py` → `assess.py` → `validate.py` 复核。历史归档已下载时无需再次获取。`frozen.json` 保存运行前的规则和数据清单哈希；不修改文件后反复试跑直到盈利。

`selection_trace` 中记录决策时刻、排行榜时刻、决策前持有、补位后持有和本次补入币种。价格/持仓数据缺失仍使完整路径无效，不虚构退出价格。原来的因果缺失隔离规则保留。
