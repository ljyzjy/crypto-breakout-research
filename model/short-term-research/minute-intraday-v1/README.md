# 分钟突破策略：独立研究目录

本轮只研究这一套策略；未重跑旧策略，未更改正在运行的 DailyMomentum 模拟账户，不连接交易账户。

## 固定规则

历史全池日线资格 → 流动性前20 → 每小时6小时收益/24小时波动排名 → 正值前三/负值后三 → 15分钟EMA20方向 → 1分钟突破前20分钟高低点与成交额确认 → 下一分钟执行。

止损为1.5倍15分钟ATR14，止盈为2倍止损距离，最多持有60分钟。北京时间22点不再开仓、23:55清仓；退出后补位，排名下降本身不退出。最多2仓、每天最多6次开仓、同币60分钟冷却。

每笔计划风险0.25%，总计划风险≤0.5%，总名义仓位在开仓时上限1×。日亏1.5%暂停至次日；回撤5%减半新增风险、8%平仓并暂停整个历史路径。5×上限尚未启用。

## 数据与执行边界

- `protocol.json`、`registration.json`：观察新策略收益之前固定的方案、数据计划哈希与注册时间。
- `data-manifest.json`：官方1分钟成交价、1分钟标记价格和历史资金费率归档；每个归档检查官方SHA256。
- `daily-pools.json`、`hourly-ranks.parquet`：只使用当时已收盘信息的资格与排名。
- `quarantine.json`：只有已知缺口生效后才移除候选，不倒删历史，不删除持仓亏损。
- `frozen.json`：候选收益计算前固定的规则、引擎、特征与数据哈希。
- `results/`：五个预设场景的逐分钟权益、成交、入场审计、指标。
- `validation.json`：多空费用/资金费率、双触发、风险预算、未来截断和现有模拟保护检查。
- `seconds_observer.py`：有限时长的公开WebSocket采集与报价模拟适配器；只观察BTC/ETH数据通道，不是新的全池模拟盘，不向交易所发送订单。

一分钟K线只能得到保守的分钟撮合估计。不能据此声称测出了秒级成交顺序、挂单排队、真实订单延迟或秒级盈利。固定滑点、以所在分钟开盘标记价近似资金费率名义金额、未还原历史数量步长等限制均在报告与网页列出。

## 运行

在本项目工作目录使用 `work/freqtrade-env/Scripts/python.exe`：

1. `prepare_data.py`：固定资格和下载计划、下载并校验数据，可恢复未完成下载。
2. `run_study.py`：检查测试、计算特征、冻结源码、仅运行此策略的五个成本/执行场景、生成报告。
3. `validate.py`：源码与数据哈希、真实数据前缀、真实订单前缀、风险与资金账本检查。
4. `seconds_observer.py --duration 90`：90秒公开行情观察；无账号、无密钥、无实盘权限。

网页：`http://127.0.0.1:8765/minute-research`。日期筛选展示连续回测的权益切片，不会重置初始仓位或风控，也不会启动其他策略回测。

历史区间已在之前的研究中被使用；时间分段只说明稳定性，不能称为未见样本。负收益结果原样保留，未进行参数搜索。8%暂停后的现金期仍计入完整区间收益及年化，必须同时查看暂停日期和实际交易天数。
